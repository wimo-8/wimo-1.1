# سوقIQ — SooqIQ
منصة رقمية عراقية لبيع المنتجات والخدمات الرقمية مع بوابة احترافية للمصممين والمطورين ولوحة تحكم للإدارة.

## التشغيل المحلي
1. تأكد من وجود Node.js 18+ و Docker.
2. انسخ `.env.example` إلى `.env` وعدل القيم عند الحاجة.
3. شغّل قاعدة البيانات:
   ```bash
   docker-compose up -d
   ```
4. ثبّت الحزم:
   ```bash
   npm install
   ```
5. طبق المهاجرات وولّد العميل:
   ```bash
   npx prisma migrate dev --name init
   npm run prepare
   ```
6. أضف البيانات المبدئية (يتضمن سوبر أدمن موسى الحيدري):
   ```bash
   npx ts-node prisma/seed.ts
   ```
7. شغّل التطوير:
   ```bash
   npm run dev
   ```
8. افتح المتصفح على http://localhost:3000

## الاختبارات والجودة
- تشغيل وحدات:
  ```bash
  npm test
  ```
- فحص E2E (يتطلب خادم يعمل تلقائياً):
  ```bash
  npm run test:e2e
  ```
- بناء الإنتاج:
  ```bash
  npm run build
  ```

## ملاحظات أمنية وتشغيلية
- المصادقة عبر OTP فقط مع أرقام عراقية (آسياسيل/زين)؛ الرمز في التطوير ثابت مع تسجيل في السجلات.
- الأكواد الرقمية محفوظة بشكل مشفّر في قاعدة البيانات.
- واجهات الإدارة محمية بالجلسات وتتحقق من الصلاحيات (RBAC) مع سوبر أدمن واحد: موسى الحيدري.
- إعدادات الدفع والتعليمات يمكن تعديلها من جدول Settings (واجهة الإدارة المبسطة جاهزة للتوسعة).

## بنية المجلدات
- `app/` صفحات Next.js (متجر، تسجيل، أوامر، بوابة محترفين، لوحة تحكم).
- `lib/` الأدوات المشتركة: Prisma، OTP، Auth، RBAC، Validators.
- `prisma/` مخطط القاعدة والبذور.
- `tests/` وحدات و E2E.
- `public/` الأصول، المانيفست والأيقونة.
